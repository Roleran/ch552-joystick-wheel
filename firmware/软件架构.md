# 软件架构

两个工程都是 CH552、内部 24MHz 的 PlatformIO 程序。用户代码停在引导区 `0x3800` 之前，USB 端点缓冲占 xram `0x0000` 起的 148 字节，普通变量从 `0x0094` 开始。

在对应目录执行 `pio run`。烧录用的 Intel HEX 会复制到工程根目录。

## 文件

| 文件 | 职责 |
|---|---|
| `src/startup.c` | `main`。毫秒计数器固定在寄存器组 1，USB 中断转给 `USBInterrupt` |
| `src/board.c` | 24MHz 时钟、Timer0 毫秒、微秒延时、端口模式、8 位 ADC |
| `src/app.c` | 摇杆、按键和模式 |
| `src/userUsbHidKeyboardMouse/` | HID 键盘加鼠标。报告 1 是键盘，报告 2 是鼠标 |
| `src/include/ch5xx.h` | 芯片寄存器 |
| `src/ws2812.c` | 只有 v1。P1.7 单线灯，滚动蓝 `(0,0,40)`，鼠标琥珀 `(48,24,0)` |

`apply_ch552_pre.py` 打开 large 模型并定义 `CH552`、`USER_USB_RAM=148`。`apply_ch552.py` 把链接起点设到 xram 148，并检查复位、Timer0、USB 三个入口都是跳转。

## 启动和循环

`init` 选内部 24MHz，等 RC 稳定，再让 Timer0 每 125us 溢出一次。8 次溢出是 1ms，`millis` 读这个计数。`setup` 配置引脚并做 USB 枚举，之后 `loop` 一直轮询。

ADC 中心是 128，死区 20。滚轮只看摇杆 1 的 Y 决定方向，X 只缩短间隔。刚出死区 180ms，Y 打满减去 108ms 得到 72ms，X 再最多减去 36ms，下限 36ms。每次只发 1 格滚轮。

鼠标位移是偏移除以 8，每 16ms 最多发一次，Y 方向取反。按键消抖 30ms，只在按下沿或松开沿动作。

## 两个版本的差异

v1 只有一个摇杆。P1.6 在滚轮和鼠标之间切换，切换时清掉残留的移动和滚轮。P1.4、P1.5 在两种模式里分别是加速/左右、滚动/上下。

v2 两个功能同时运行，用各自的计时，互不等待。摇杆 1 固定滚轮，P1.6 只切换摇杆 2 按键：默认 `MOUSE_LEFT`，切换后是 `KEY_RETURN`。摇杆 2 的 P1.1、P3.2 固定移动鼠标。P3.0、P3.1、P3.3、P3.4 固定为方向键，按下放进键盘报告，松开从报告里删掉。

v2 的鼠标报告在发出后把 X、Y、滚轮清零。滚轮和移动、按键共用同一份鼠标缓冲，不清掉的话下一次报告会把上一次的相对位移再发一遍。
